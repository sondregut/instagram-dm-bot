# NovaSpeed interested contacts and comment history

The NovaSpeed Sheet previously listed only contacts who supplied an email. Qualifying commenters who were still awaiting email were invisible in the Leads tab. The existing Leads and Messages tabs remain intact; new Contacts and Comments tabs expose that earlier stage without inflating the email count.

For the two immutable NovaSpeed account identities (`sondre_pv` and `novaspeedtiming`), authenticated qualifying comment events now create an account-scoped contact and per-comment record before the DM session gate. Repeated qualifying comments during cooldown are recorded once each without starting another send. Contact IDs use account and Instagram user IDs; comment IDs use account and provider comment IDs. A username is used only when present and valid in the source payload. Profile URLs are derived from that observed username. Display name, post permalink, original comment text and timestamp are preserved when supplied; missing historical fields are explicitly unavailable.

The existing Sheet worker writes Contacts and Comments through its stable-ID, single-writer, retry-safe path. Contact email status joins only the exact NovaSpeed lead/session. Comment send status joins only the exact NovaSpeed comment receipt. All writes use RAW values; the worker preserves manual Leads F:H, Messages I, Contacts N:O and Comments Q. No other app leads, automatic follow-up emails, historical Instagram replays, new grants or credentials are introduced. Existing NovaSpeed DM wording, strict bare-address parsing, pause/opt-out rules, MINDSET and TrackSpeed behavior remain unchanged.
